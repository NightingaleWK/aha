# What’s New · v0.4.0

## 首次公开发布

aha 是本机 Codex 用量台账与费用材料工具，可只读同步 CC Switch 来源，按项目和北京时间范围分析用量，并保存可追溯的报销材料。这些能力在本次首次公开发布前已经存在；下面列出首次发版包含的近期变化。

## 本次亮点

- **兼容 CC Switch 24 的用量同步**
- **按版本下载 Windows 单文件程序**

## 新增功能

- **按版本下载 Windows 单文件程序**：通过GitHub Releases提供对应版本的Windows x64 EXE、中文What’s New和SHA256校验信息；程序显示、文件属性与发布版本保持一致。

## 问题修复

- **兼容 CC Switch 24 的用量同步**：支持读取结构版本23和24的CC Switch数据库与SQL备份，遇到未知结构版本会明确提示；已有用量、归属和冻结材料保留原有规则。
- **加强试用资料重建的目录保护**：手动重建试用资料时，使用等价路径写法也能正确识别保护目录，并在备份或清理前拒绝操作。

## 升级说明

- 下载Windows x64 EXE，退出旧程序后使用新文件；发布流程不会移动或改写你的个人资料目录。
- 本版尚不包含应用内检查更新或自动安装，后续版本从Releases页面下载。
