# What’s New · v0.8.0

## 兼容性与升级提醒

- **用量台账只保留逐笔明细**：移除旧 CC Switch 历史日汇总及其用量入口。趋势、按日查看和新报销材料统一从逐笔明细计算，已保存的报销材料可继续下载原包。
## 本次亮点

- **修复上下文压缩引发的同步误报**
- **用量台账只保留逐笔明细**
- **用量首页增加费用趋势**

## 新增功能

- **用量首页增加费用趋势**：首页默认查看近 14 天，费用趋势与可用成本并排显示。点日柱查看对应日期，生成报销材料时可在侧栏先核对本次范围和参考成本。项目管理和报销记录使用紧凑表格。

## 问题修复

- **修复上下文压缩引发的同步误报**：识别超长的 Codex 上下文压缩记录并重读受影响的文件，修复由此产生的「单条日志过长」和「累计用量无法核实」提示。两端完整覆盖时显示「已同步」。

## 升级说明

- 首次打开旧台账会先创建完整回退备份，再移除旧历史汇总。旧汇总曾计入全部用量时，历史参考费用会相应减少。
