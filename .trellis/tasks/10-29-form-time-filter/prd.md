# 清爽表单与便捷时间筛选

## 目标与用户价值

把“清爽表单”与便捷时间筛选合并为一次完整改造：用户更容易选择项目、时间和用量范围，常用操作更少，统计与导出仍有一致、可信的用量依据。

本任务已获用户明确授权创建并进入方案设计，当前状态为 `in_progress`。历史日汇总采用用户于 2026-10-29 确认的方案 A；用户已在完整最终方案之后明确回复“进入实施”，批准本版方案。

## 已确认背景与方向

- 用户选择“清爽表单”方向：清晰的字段标签、统一高度与圆角、沿用 aha 青绿主色、可搜索项目下拉和选中标记。
- 时间筛选参考用户提供的 CCS 图片：快捷范围、开始/结束日期和时间、日历、“结束时间跟随当前时刻”、取消与确定。
- 合并为一个 Trellis 任务，覆盖首页筛选与相关页面的同类表单组件，不拆成相互脱节的外观修改和查询修改。
- 现有首页仅支持整天的开始/结束日期，快捷范围为今天、近 7 天、本月和全部日期。证据：`src/aha/web/index.html:38`、`src/aha/web/index.html:44`、`src/aha/web/app.js:165`。
- 现有查询按北京时间含起止日；按时间筛选需同时覆盖统计、四个分页视图、保存、修订和导出。证据：`src/aha/queries.py:47`、`src/aha/queries.py:307`、`src/aha/batches.py:289`、`src/aha/evidence.py:418`。
- 历史来源日汇总没有逐笔发生时间，既有规范禁止把它按小时或比例拆成虚构明细。证据：`.trellis/spec/backend/usage-evidence-contract.md` 的“核算、覆盖与归属”。

## 需求

| 编号 | 需求与可观察行为 |
| --- | --- |
| R01 | 全站同类表单统一采用清爽风格，覆盖首页、项目管理、报销记录及相关弹窗；保留现有清晰字号和键盘焦点。 |
| R02 | 项目下拉允许搜索已有项目；全部项目、未归属和清除人工指定等特殊选项沿用各自现有含义，不把相似名称当成同一项目。 |
| R03 | 首页“可用用量/全部用量”并排切换，保持前者用于新建报销、后者仅供查看的业务限制。币种、依据等其他选择按场景使用统一下拉。 |
| R04 | 时间筛选提供当天、近 24 小时、近 7 天、近 14 天、近 30 天、本月、全部；允许通过日历及可编辑日期/时间选择自定义区间，统一按北京时间解释。 |
| R05 | 时间面板有编辑中的条件和已生效条件；取消保留原预览，确定后采用新范围并更新预览。首页明确显示实际生效的起止时间。 |
| R06 | “跟随当前时刻”在每次用户更新预览时重新取当前时刻；不增加后台采集或定时同步。保存和导出沿用已经预览的具体范围，不悄悄扩展到保存时刻。 |
| R07 | 明细、历史日汇总、每日统计、模型统计、指标、排除说明和导出使用同一生效范围。已确认采用 A：历史日汇总仅在其完整自然日被覆盖时计入；部分日汇总不计入，提示“统计不完整”并允许用户主动改查整天；其他条件合法且存在确定的可用成员时允许保存该部分，材料保留完整性说明。 |
| R08 | 控件保持鼠标和键盘可操作：方向键、Enter、Escape、Tab、外部点击收起、搜索无结果、禁用状态、长名称、弹窗内焦点和窄窗口均有明确表现。 |
| R09 | 旧整天日期查询语义及既有报销记录保持可解释；旧版本材料仍下载原字节，新建/修订材料明确记录采用的时间范围。 |
| R10 | 改变已生效范围清除原预览、勾选和保存身份；数据、归属或占用变化仍按现有权威校验重新预览，精确时间不能绕过数据核对和报销占用。 |
| R11 | 样式和查询资源随本机程序提供，离线可用；不要求用户安装前端运行环境，不加载远程字体、脚本或组件服务。 |

## 时间范围口径

| 范围 | 用户看到的含义 |
| --- | --- |
| 当天 | 北京时间当天 00:00 起；跟随开启时截止本次预览时刻。 |
| 近 24 小时 | 截至本次生效结束时刻的连续 24 小时，按来源记录的秒级精度统计。 |
| 近 7/14/30 天 | 包含今天的最近 N 个自然日，从第 N 个自然日 00:00 起；沿用现有“近 7 天”的计日方式。固定结束的快捷范围以该结束时刻所属自然日为最后一天。 |
| 本月 | 北京时间本次生效结束时刻所在月份的 1 日 00:00 起。 |
| 全部 | 本地已保存依据覆盖的完整自然日范围；此时不使用跟随开关，空库时明确提示暂无可查询日期。 |
| 自定义 | 可编辑起止日期和分钟；起止分钟都包含，例如 10:00 到 11:00 包含 11:00:59。跟随开启时结束采用本次实际预览时刻。 |

固定快捷范围保留其确切时刻，重新更新预览不滚动；手动改动时间端点转为自定义。页面显示服务端实际采用的范围，不只显示快捷名称。

| 编号 | 对应需求 | 验收结果 |
| --- | --- | --- |
| AC01 | R01、R02 | 各页面的同类控件外观一致；项目搜索、特殊选项、动态新增/改名及程序回填后显示值与实际请求一致。 |
| AC02 | R03 | 并排切换正确更新范围；“全部用量”仍无法新建报销，切回“可用用量”按真实剩余用量预览。 |
| AC03 | R04、R05 | 所有快捷范围可选，自定义可选到分钟；取消不改变原条件，确定后无需再点一次“更新预览”；起止无效时有清楚提示。 |
| AC04 | R04、R06 | 当天、连续 24 小时和 N 个自然日可区分；跨日、跨月、闰日及非北京时间浏览器下结果正确；手动结束分钟完整计入、相同起止分钟表示该一分钟；跟随模式刷新时重取时刻，保存时不改变已预览成员。 |
| AC05 | R07、R10 | 边界记录、完整日汇总、待核对与已占用记录按同一口径进入四个视图和指标；部分日汇总不进入合计，其完整全天金额不能冒称为所选小时内的排除金额；无确定可用成员时不能新建报销，有确定可用成员时可保存并在材料中保留不完整说明。 |
| AC06 | R07、R09 | 页面与完整导出的成员、金额和 Token 一致；新材料包含精确范围；旧记录的查看、仅改用途、状态流转和原包重下载仍正确。 |
| AC07 | R08 | 真实浏览器验证键盘、点击外部、弹窗内操作、长名称、搜索无结果和禁用状态；1440/1366/1280/430/375 宽度可用，不靠缩字解决布局。 |
| AC08 | R09、R11 | 原整天请求保持兼容，新增资源由本机服务与打包收集；产品运行不依赖外网。 |
