# 实施与验收

1. 原生日志读取、旧游标重读与原生来源中的明细身份处理。使用普通、压缩、分段日志回归。
2. 持久化迁移和旧投影入口。按事务验证旧版本结构、清理活动数据、重建受影响的可用性和精确统计。验证旧资料自动备份和现有恢复流程。
3. 用量查询、项目归属、新材料和页面去除历史来源日汇总。核对保存、查看的真实入口，以及旧材料下载和防重。
4. 执行完整 Python 和 Node 回归、Ruff、strict mypy、语法检查、变更校验。使用隔离旧台账验证结构、备份、精确金额、既有材料和失败回滚，实测主要浏览器交互。
5. 编写中文发版片段并对齐相关规范。原生 Windows 先验收 Directory，然后构建 OneFile，验收实际桌面副本。使用真实台账核对迁移与两端同步，只记录脱敏验收统计。
6. 清理任务临时目录和构建中间物，保留原始回退备份、桌面成品和必要验收记录。按项目流程合并确认提交计划和公开发布选择。
