# 发版评估

## 本地交付时的评估

公开基线为 v0.7.0。建议合并到 v0.8.0。累计待发内容包括工作台改版、退出旧日汇总和同步误报修复。迁移会改变使用过旧汇总的历史总额，适合在次版本中集中说明自动回退备份和新材料口径。

## What’s New

- 用量首页增加趋势，按日下钻，项目和报销列表更紧凑。
- 用量台账只保留逐笔明细。升级前自动创建完整回退备份。
- 修复超长上下文压缩记录引发的同步误报。

## 发布条件

本机迁移、原生 Directory 和 OneFile、桌面副本、真实两端同步、Excel 和 A4 检查已通过。正式候选还需功能和发布 PR、云端 Windows 候选验证以及托盘实点。

## 本地确认

用户已确认本地提交。本次发版评估沿用 v0.8.0 的累计待发安排。

## 正式发布

2026 年 11 月 26 日，v0.8.0 正式发布。桌面 EXE 经核对与公开下载一致，用户确认实测通过。正式候选验证了升级前备份、旧汇总移除，以及 Windows 和 WSL 完整同步。 [GitHub 发布页](https://github.com/NightingaleWK/aha/releases/tag/v0.8.0) · [Windows 验收回执](../../../../../.release/acceptance/v0.8.0-windows.json)
