# Research · 首页费用趋势的数据来源

- 研究问题为如何按一次成功预览的筛选条件绘制参考成本趋势，并限制查询与显示规模。
- 范围为本仓库的 SQLite 投影、首页分析接口、页面请求与验收入口。
- 日期为 2026-11-25。

## 现有依据

- 首页预览从 `POST /api/analysis` 获得 `analysis_id`、服务端已解析北京时间区间、项目、用量模式和三种 revision。服务端最多缓存 24 个分析，读取失效 id 返回 `analysis_expired` 409。参考 [server.py](../../../../src/aha/server.py#L673) 和 [分析登记](../../../../src/aha/server.py#L734)。
- 每日表格按日期、项目、模型分组，单页 1 至 200 行，可跨页拆分同一天，聚合总行数允许未知。完整导出会迭代全部分组。参考 [queries.py](../../../../src/aha/queries.py#L708)、[分组和游标](../../../../src/aha/queries.py#L786) 和 [HTTP 分页入口](../../../../src/aha/server.py#L848)。
- `_statistics_source` 向上提供统一的 `day`、`state`、参考成本等列。`daily=True` 读完整日投影，默认优先读完整月投影并将月键映射为当月首日。首尾未完整覆盖的日子从事实按事件秒读取未抑制的明细。项目约束在各分支一致。参考 [queries.py](../../../../src/aha/queries.py#L126)。
- 首页的可用成本只含 `available`，全部参考成本包括 `available` 和 `claimed`。待核对记录另计，逐条列表可展示其状态。自豁免修订使用额外的事实级口径。参考 [queries.py](../../../../src/aha/queries.py#L513)。

## 建议

新增只读 `GET /api/analysis/{id}/trend`。沿用服务端的分析读取和认证机制，由 Store 转发到 `queries.py`，在同一 `read_connection()` 内校验 revision 并执行聚合。此接口接受首页分析 id，当前修订继续使用自己的分析和表格。保存、导出、材料下载和旧库沿用已有契约。

1. 从分析取实际时间边界，按选区跨度选择粒度。最多 31 个自然日时按日，最长 31 个自然月时按月，随后可按年。如果历史跨越超过 31 年，可按 `ceil(覆盖年数 / 31)` 个连续自然年组成一组。较长区间继续展示全选区成本。首尾柱按实际时间边界截取，标签应与可核对的时间范围一致。
2. 复用 `_statistics_source(analysis, daily=grain == "day")`。按 `day`、日期字符串的月/年部分或连续年组聚合，使用 SQL `decimal_sum(total_cost_usd)`。筛选状态与首页摘要一致。月/年趋势可利用完整月投影，只有不完整的月和日读取更细的数据。
3. 响应最小形状为粒度和有序点位，例如 `{grain, points: [{period, total_cost_usd}]}`。如需提示无参考价，可附 `record_count` 与 `unpriced_count`。时间标签和空日期位置按已解析区间生成。全空、仅遗漏日汇总和确有零额分别呈现，货币标签沿用原精确字符串。
4. 首页收到成功分析后独立加载趋势，显示状态由 `analysis_id`、`filterGeneration` 和停止状态保护。向 `api` 传同一谓词，避免旧 409 清当前预览。当前网络错误显示在趋势区域，当前权威数据失效沿用现有全局失效。失效时清空图，表格翻页和换标签不重查图。参考 [api](../../../../src/aha/web/app.js#L83)、[invalidate](../../../../src/aha/web/app.js#L194) 和 [renderPreview](../../../../src/aha/web/app.js#L1244)。

单独的读取允许先看汇总和表格，给趋势留自己的加载及失败状态。另一可行形态是在首页分析请求选择性返回有界趋势，可共用同一读快照，但需要扩展现有分析生产路径并把取图耗时并入首次预览。逐页抓每日表格会增加查询与传输量，单拿第一页则没有全量依据。用最近 31 天裁剪长选区可以节约一期实现，选区与图的范围会有差异。

如果保留原型的每日柱点击，可给现有 `kind=daily` 读取加一个可选 `day` 参数。只接受分析覆盖的自然日，在同一 SQL 上追加日约束，以原选择哈希和日期派生该页的游标作用域。表格切到每日并显示可清除的日期标记，请求身份也包含该日期。总计与保存继续使用原分析。这个方案局限在日表读取，但多出一组分页、请求切换和可发现性验收。基础交付可先让日、月、年柱都提供可键盘读取的精确金额。参考 [游标选择](../../../../src/aha/queries.py#L683) 和 [日表查询](../../../../src/aha/queries.py#L786)。

## 验证与边界

- Store 侧用有多个项目及模型、跨首尾部分日和完整月、占用与待核对并存的夹具。逐粒度用精确十进制核对所有图点之和等于同一分析摘要，另测无成员/仅遗漏历史日汇总、长范围点数上限，以及索引投影与部分日事件秒范围。参考 [test_time_ranges.py](../../../../tests/test_time_ranges.py#L194) 和 [test_analysis.py](../../../../tests/test_analysis.py#L168)。
- HTTP 侧从真实首页分析 id 读取一个有界响应，验证认证、错误 id、revision 变化后的 409 及修订隔离。客户端测试旧成功、409、断连与当前失效四种顺序，参照现有 [web_state.test.cjs](../../../../tests/web_state.test.cjs#L505)。
- 实际浏览器切换项目、用量模式和时间，核对图、汇总与材料范围，并检查窄窗口与键盘读取。图点若提供下钻，验收应明确它是局部表格查看还是一次显式重选区间。局部查看继续使用原成功分析保存，避免图表的浏览动作静默更换报销范围。
- 产品页面的 CSP 只允许本机静态资源。图形尺寸可用 Canvas 或 CSSOM 控制，精确金额和可访问描述使用正常 DOM。参考 [server.py](../../../../src/aha/server.py#L1109)。
