# aha 工作台界面改版

## 目标

把用户选定的工作台做进 aha。打开首页就能看费用、趋势和用量明细。项目管理和报销记录便于逐行核对，界面文案用直接的动作和结果说明。

## 背景

用户选定暖灰与松绿的工作台作为首页，项目管理和报销记录使用紧凑表格。真实页面已有本地同步、时间筛选、目录关联和报销冻结流程。首页的按日明细按日期、项目和模型分页，完整的趋势统计与分页查看使用同一份已确认的用量范围。

## 要求

- **R1 首页布局。** 左侧导航和暖灰底色贯穿三页。首页按筛选、费用趋势与摘要、用量明细排布。同步及状态放到页头，来源、备份与还原等管理入口集中摆放。未配置、部分成功、失败、待核对和待归属时显示具体状态及可用动作。
- **R2 筛选与统计。** 首页默认近 14 天，项目和用量范围切换后更新预览。时间面板确认后查询，取消或 Escape 保留已应用条件。趋势、参考成本、计数和 Token 对应同一个成功预览的项目、实际北京时间和用量口径。点日柱可查看该日汇总，报销侧栏仍显示完整预览范围。空结果、部分日历史汇总、缺价和失败有各自的反馈。保留四种明细视图和分页。
- **R3 报销侧栏。** 从可用用量摘要打开，显示本次采用的项目、实际时间、记录数和参考成本。申请金额与参考成本分开显示，金额可留空或为零，填写时需要依据。使用既有保存、占用、冲突、下载和重试规则。预览失效时保留已填草稿，引导重新核对后再保存。
- **R4 紧凑列表。** 项目管理用表格展示项目、目录、已归属用量和参考成本，可以查看费用、管理目录和确认旧项目的目录关联。报销列表用紧凑表格展示记录、范围、状态和金额，详情可查看修订、生命周期动作和指定版本的材料。完整路径、用途和精确时间在相应位置可查。
- **R5 文案与组件。** 按钮使用「立即同步」「更新预览」「生成报销材料」「保存并下载」等清楚的动作。已占用、待核对和统计不完整说明给出具体原因和下一步。短动效用于状态反馈和侧栏打开，遵循系统减少动效。控件支持键盘、可见焦点、弹层关闭与焦点归还，窄窗口保留可读字号和完整币种。
- **R6 交付。** 真实页面使用随程序内置的资源。按项目约定交付与最终源码一致的 Windows 单文件 EXE，放到实际桌面并从交付位置启动验收。提供中文 What’s New 片段和真实验收记录。

## 验收

- [x] **AC1（R1、R5）** Windows 浏览器在 1440、1366、1280、430 和 375 像素宽度检查首页及两种紧凑列表。验证同步、数据来源、数据核对、备份、退出和窄窗口表格入口。长项目名、路径、金额和 CNY／USD 均可读。
- [x] **AC2（R2）** 验证默认范围、项目和用量切换、日期确认与取消、分钟边界、跟随当前时刻、部分日提示和改查整天。用隔离合成台账对照趋势各段、摘要、明细和材料金额。覆盖图表局部查看及相关分页、长范围、缺价、空结果和迟到响应。
- [x] **AC3（R3、R5）** 从最新可用预览打开侧栏，验证焦点、低动效、金额空值和零、缺少依据、预览失效、冲突、重试、下载失败与重下。旧冻结版本和旧 ZIP 可读，原包字节一致。
- [x] **AC4（R4、R5）** 用紧凑项目表打开目录关联，从预览影响到确认保存。用紧凑报销表打开有效和历史记录，验证可见动作及下载。键盘可达行内按钮与详情，关闭弹层后焦点可继续操作。
- [x] **AC5（R6）** 运行仓库检查与真实页面回归，依次验收原生 Directory 和 OneFile。确认桌面副本的 SHA-256、启动、主要流程、材料和退出。保存对应的小型验收记录并清理临时文件。

## 范围与约束

改动集中于三页外观、首页查询和报销入口、受影响的界面文案，以及支持趋势的只读数据。时间、计价、项目归属、占用、冻结材料、备份和退出继续以现有产品合同为准。GitHub 公开发布由独立的发布评估和用户授权决定。
