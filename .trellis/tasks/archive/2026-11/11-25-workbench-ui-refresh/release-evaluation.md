# 发版评估

## 本地交付时的评估

- **公开基线**为 v0.7.0，源码 `fe36e96`。远端 main 后续一条提交是 v0.7.0 验收归档。累计待发的用户可感知改动为本分支的工作台改版。
- **建议版本**为 v0.8.0。首页布局、新趋势、报销侧栏和列表密度是一次可见的体验更新，按功能发布走次版本。本机已交付的开发构建显示源码版本 v0.7.0。
- **What’s New 预览**　用量首页增加费用趋势。首页默认查看近 14 天，费用趋势与可用成本并排显示。点日柱查看对应日期，生成报销材料时可在侧栏先核对本次范围和参考成本。项目管理和报销记录使用紧凑表格。
- **公开验收缺口**为功能与发布 PR 流程、云端候选构建和托盘实点。实际本机结果集中在[验收记录](verification.md)。
- **用户选择**为「积累到下一版」，于 2026 年 11 月 25 日确认。保留 v0.8.0 建议及适用的公开验收条件。
