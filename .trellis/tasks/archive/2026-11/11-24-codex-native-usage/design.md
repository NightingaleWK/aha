# 双端原生采集设计

## 来源和读取

| 来源 | 查找与绑定 | 读取方式 |
| --- | --- | --- |
| Windows | 使用当前用户有效的 `CODEX_HOME` 或默认 `.codex`，界面支持确认实际根 | 原生文件读取，处理大小写、卷与文件替换 |
| WSL | 从明确选中的发行版与用户内的 `CODEX_HOME` 或默认 `~/.codex` 发现，允许确认实际根 | Windows 调用 `wsl.exe` 在发行版内部做有界的清单和分段文件读取 |

实际读取由同一来源适配接口提供。WSL 命令只接受已确认的发行版和路径参数，使用固定只读命令或脚本、长度分帧和有界标准输出。试验先验证当前发行版内置工具与增量成本。枚举和小文件批量读取尽量复用一次短进程，关闭句柄，维持桌面单文件交付。WSL 停止或不可达时返回明确状态，Windows 的工作可以独立提交。

已配置的根、发行版、安装和还原身份定位一个来源实例。两端物理身份不同，逻辑会话和事件可以相同。检查目录边界并验证实际打开的文件属于绑定根。续写旧日期目录时结合已登记的文件、会话索引提示和有界的补充枚举。目标判据是按增量做读取，索引缺失也能通过同步或补采恢复覆盖。

## 原生日志解析

1. 重用 `session_meta.py` 的有界头部识别、压缩和项目目录依据。会话头提供会话、目录和父会话候选。上下文提供模型与当前会话的继续信息。
2. 从日志格式分派已验证的用量事件解析。普通记录用 `token_count` 的累计与逐次数据恢复经验证的用量增量。若同一真实请求同时出现 `token_usage_record` 和 `token_count`，同一证据对只出一笔。缺少基线、累计回退和多版本分段先识别，不能证明增量的部分留待核对。
3. 尾部仍在写入时，只处理已完整读取的事件。压缩归档按有效内容与会话关系核对，设解压、单行和作业预算。分卷续写从经验证的前序高水位恢复。分叉以已验证的父前缀区分重放与新增，缺依据时保留原因和范围。
4. 将 UTC 或带偏移的事件时间按现有时间合同归一。生效模型优先使用可验证的实际记录，其次保存日志中声明的模型并标明依据。对输入、缓存、输出与推理量按事件版本归一，避免在已包含字段上重复累计。
5. 只允许保存身份、时间、目录、模型、计数、费用、解析来源及状态。管道中的原始行在本次读取中处理，持久化投影、审计记录和报销包保持既有隐私边界。

## 逻辑事件与物理进度

| 用途 | 依据 |
| --- | --- |
| 源位置与读取进度 | 来源实例、物理文件身份或等价指纹、编码、已确认偏移、续写状态、最后检查时间 |
| 原生事件身份 | 已验证的逻辑会话/分卷与事件语义，包含可靠事件或关联标识及稳定的消歧依据 |
| 跨文件重复 | 同一事件出处、已核验的事件语义及内容指纹。跨端路径、mtime、压缩名和偏移可以变化 |
| 疑似重叠 | 会话、时间、模型、计数等作为候选，处理多匹配、冲突和未确认的投影，不合计可疑成员 |

偏移用于继续读取，使用长度与身份检测文件增长、截断和重写。即使修改时间未更新也可识别增长。状态变化时从确定的边界重放，已发布的事实由逻辑身份防重。计数是否缺失、哪些文件需重试与游标一起持久。确定读完的记录、来源证据和对应游标在一个发布事务提交，提交失败保留可重放状态。

## 写入、展示与兼容

- 使用 `sync.py` 现有的分批暂存、版本化事实和单写入发布，改由规范化用量投影进入同一台账。启动与手动入口继续使用作业状态。每个来源的中断、失败和最近成功独立显示。
- 新增台账记录沿用明细合计、时间切片、目录归属和金额展示。新增的游标与事件索引使用目标 schema 5。持久化稳定事件和来源证据，供后续还原时重新关联并防重。
- 项目路径沿用原生 Windows/POSIX 语义。`C:\` 和 `/mnt/c` 可能指向同一目录，保留已确认的目录及显式规则。失去当前日志不撤销旧目录。跨端来源产生不同目录证据时进入现有核对链。
- 模型参考价使用跟随程序发布的有版本价格表和精确十进制，每笔留存计价依据。拟采用经核对的公开 API 参考价及已确认的本机参考口径，未知模型保持未定价。订阅实际扣款和模型参考金额维持现有区分。
- 迁移时历史参考金额和历史身份由历史子任务保护。原生事件的坐标和匹配依据作为交接合同，保持可单独验证。

## 异常与成品验收点

| 情况 | 用户可观察结果 |
| --- | --- |
| 一端目录错误、WSL 不可达 | 对应源给出原因和最后成功时间，属于另一端的可读事实可提交 |
| 运行中重写、尾行不完整、归档切换 | 从已确认边界续读，已核实事件保持一份，不确定的范围可见 |
| 文件或压缩超限、格式未知 | 限制当前范围，保留可查历史和已确认事实，页面标明部分覆盖 |
| 取消或中途崩溃 | 已提交端及已验证游标仍可用，未完成片段可重试，退出释放句柄与子进程 |
| 模型未知、目录冲突 | Token 继续可分析，金额或归属采用对应的未知、待核对状态 |
