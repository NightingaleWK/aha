# 双端原生 Codex 用量采集

## 目标

从 Windows 和 WSL 实际使用的 Codex 会话目录读取逐笔用量，增量写入同一个 aha 台账，并在现有的项目与统计页面可核对。承接主任务 R1、R2、R3 与 R5。 [主需求](../11-24-codex-dual-source-usage/prd.md)

## 要求

- 支持已确认的 Windows 和 WSL 数据根、普通会话和压缩归档。Windows 桌面进程负责同步，用户现有的 WSL 环境负责文件读取。
- 保存可核查的用量、事件时间、会话及分支依据、项目目录和模型。价格有确定依据时产生参考成本，未知项有可见状态。
- 断开、取消、读取上限与不完整记录按来源报告，保留已有资料及每端独立进度。重复读同一事件、跨端复制、归档与续写保持幂等。
- 复用现有本地查询、项目归属、核对与报销选择。两端数据使用同一时间和成本口径。

## 验收

| 编号 | 结果 |
| --- | --- |
| N1 | 现有真实 Win/WSL 会话样本能采到记录，Token 字段与原生事件投影核对，目录按现有项目规则归属。 |
| N2 | 重导、断点恢复、跨端复制和普通日志转压缩均不重复入账。续写到旧会话时能采到新实际用量。 |
| N3 | 保留难以确定的事件及原因，重复快照、累计重置、子代理重放和成对事件均有验证样本。可用合计使用已确认事件。 |
| N4 | WSL 停止、超时或根失效时，Windows 能同步且另一端进度不被重置。恢复后接续，页面分别显示每端状态。 |
| N5 | 给定已定价样本和缺价样本，金额和 Token 统计准确。原生记录进入现有按项目、时间和模型查询，具备清楚的来源和覆盖说明。 |

## 依赖与交接

本子任务在隔离台账中验证原生能力，并确定可持久化投影、事件身份与游标。历史迁移、备份兼容、正式替换入口及跨版本冻结材料由[历史台账迁移与备份还原](../11-24-codex-history-backup-cutover/prd.md)接续。两个任务的源配置、应用 schema 与台账合同统一见[主设计](../11-24-codex-dual-source-usage/design.md)。
