## 风险文件及回退点

- 动态版本/PE打包不兼容：在版本PR合入前修复或回退相应改动，保留原可用成品，不改业务存储。
- What’s New生成不一致：回到源片段和候选范围修正，重新生成/检查，不手改正式版掩盖差异。
- 权限或机器人CI触发异常：停止在待审PR/草稿阶段，修复精确权限或dispatch；不降低分支保护或让无检查版本公开。
- 草稿部分上传失败：按相同版本和M恢复；正式版有冲突则发布新patch，不覆盖或改写已发布标签/资产。
